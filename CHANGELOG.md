# Changelog

## 0.2.0

- Chat-input delegation switch, off by default for every new chat, with main/worker selectors.
- Last selected model pair persisted through native DSH configuration; disabling retains preferences.
- Actual main/worker routing, hidden delegation tools in disabled chats, and budget guards scoped to enabled chats.
- Native plugin detail/row configuration pages for models, prices, role verification, fallback and limits.
- Provider catalog discovery, configured-route fallback and atomic revision-fenced saves with visible failures.
- Real profile/Loader persistence tests and browser checks for controls, restart, save refusal and narrow layouts.

## 0.1.0

- User-defined model routes and worker roles in Host configuration; client configuration-page entry omitted (fixed in 0.2.0).
- Role discovery and bounded delegation tools with optional model review, retries and fallback.
- Native-log agent/call projections and a right-sidebar box-and-arrow graph.
- Usage-based estimated costs, unknown-price handling and an optional concurrent estimate guard.
- Built Host/client installation package, English/Chinese documentation and keyless runtime/browser checks.
